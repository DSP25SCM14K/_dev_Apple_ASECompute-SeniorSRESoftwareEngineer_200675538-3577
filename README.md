# Dev Kumar — Senior SRE & Kubernetes Platform Engineer

A responsive, static portfolio highlighting production Kubernetes, compute infrastructure, reliability engineering, low-level systems, and selected software projects.

## Run locally

Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Publish with GitHub Pages

This is a static site and needs no build step. Push the directory contents to the repository's default branch, then enable GitHub Pages under **Settings → Pages → Deploy from a branch**, selecting the default branch and `/ (root)`.
